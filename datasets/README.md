# Dataset Documentation

## Primary Stage 2 Dataset

Name:
Prompt Injection and Jailbreak Detection Dataset

Source:
Hugging Face

Configuration:
core

Purpose:
Training and evaluation of binary prompt-injection detection.

Expected labels:
0 = benign
1 = malicious

Languages:
English

License:
Apache 2.0 according to the dataset card checked on 2026-09-28.

Important:
The dataset license and availability should be rechecked before
final submission or redistribution.

## Evaluation Policy

The final test split is not used for model training.

Results reported in the project are generated by our own
evaluation scripts.

Published benchmark numbers from the dataset provider are not
treated as our experimental results.
